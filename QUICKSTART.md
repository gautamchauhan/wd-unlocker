# Quick Start Guide

## First Time Setup

1. **Install the application:**
   ```bash
   ./install.sh
   ```

2. **Launch the application:**
   ```bash
   ./wd_unlocker_gui.py
   ```
   Or search for "WD Disk Unlocker" in your applications menu.

3. **Unlock your disk:**
   - Enter your WD disk password
   - Click "Unlock"
   - Enter your sudo password when prompted
   - Wait for confirmation

## That's it! 🎉

### Troubleshooting

**Can't run the script?**
```bash
chmod +x wd_unlocker_gui.py install.sh
```

**Need to uninstall?**
```bash
./uninstall.sh
```

**Prefer command line?**
```bash
sudo pipx run wdpass -u
```
